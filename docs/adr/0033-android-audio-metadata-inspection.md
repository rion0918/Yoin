# ADR 0033: Androidで音声メタデータから取り込み時間を読む

Date: 2026-10-13

## Status

Proposed

## Context

音声取り込みでは、保存前に音声の長さを確認する。現状はExpo Audioの再生準備完了を待つため、50分の音声で15秒以内に読み込みが終わらず、端末への追加前に失敗することがある。

## Decision

Androidでは `MediaMetadataRetriever` からファイルの再生時間を取得する小さなExpo Moduleを追加する。メタデータを取得できない形式ではExpo Audioへフォールバックし、iOSもExpo Audioを維持する。再生準備の待ち時間は60秒とする。

再生エンジンの初期化時間だけを延ばす方法では、長い音源のメタデータ取得が再生準備に依存したままになるため採用しない。

## Consequences

- 利点: Androidでは音声全体の再生準備を待たずに長さを確認できる。対応外形式には既存の読み取り経路を残す。
- 受け入れる欠点: メタデータが取得できない形式や端末では、Expo Audioのフォールバックに最大60秒かかることがある。実機で形式別の取り込み確認が必要。
