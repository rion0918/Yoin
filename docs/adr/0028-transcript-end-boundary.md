# ADR 0028: 原音終端を100ミリ秒以内だけ超える認識時刻を限定補正する

Date: 2026-10-13

## Status

Proposed

2026-10-13のチャットでこの実装計画の実施を指示された。計画に従い、品質受け入れと配布判断を分離し、記録はProposedに保つ。

## Context

[ADR 0023](0023-transcript-timing-review.md)は不正な認識時刻が一つでもある場合、全文を未確認の区間として保持する。実録音の最後の単語が63ミリ秒だけ終端を超え、他の発話時刻と話者照合まで無効になった。

## Decision

開始が原音内にあり終了だけが100ミリ秒以内超える場合は、検査済み原音の終端へ終了を制限する。元のoffsetとclamped_endを影響する発話に保存し、確認を必須にする。他の発話時刻・出典IDは維持する。逆転、開始の範囲外、100ミリ秒超過にはADR 0023の全文・原音保持を続ける。既存の承認済み文字起こしは置換しない。補正範囲を拡大する案は出典時刻を推測するため採用しない。

## Consequences

短い末尾超過で他の発話まで失わない。境界補正は正しい認識内容を保証しないため、原音確認が必要。63/100/101ミリ秒と逆転・開始範囲外のテストで境界を固定する。
