# ADR 0022: 制作名と完成曲名を分ける

Date: 2026-10-10

## Status

Proposed

## Context

これまでは仕上げ画面で入力した下書き名を、完成曲のタイトルにも使っていた。ユーザーは、制作名を録音開始時に決め、完成曲名は歌詞確認後に手入力することを希望した。制作中の思い出とプレイリスト内の曲を別の名前で扱う必要がある。

## Decision

制作名は録音画面で最初の録音を始める際に端末の下書きへ保存し、音声のアップロード時にも下書き名として使う。完成曲名は歌詞確認画面で別に入力し、端末の下書きと生成ジョブへ保存する。生成ジョブは曲名を固定し、完成曲レコードのタイトルにだけ使う。

ユーザーは2026-10-10に、歌詞確認後の曲名を手入力する方針を選んだ。複数のデータ層をまたぐ保存方式は、このADRで提案する。

同じ入力値を制作名と曲名に共用する方式は、ユーザーが求める使い分けを表せないため採用しない。曲名の自動生成は現行処理になく、ユーザーが手入力を選んだため対象外とする。

## Consequences

- 利点: 下書きとプレイリストの曲を別々の名前で識別できる。曲名は生成ジョブに固定され、再試行時も同じ完成曲名を使える。
- 受け入れる欠点: ローカル下書きに曲名を追加し、生成ジョブ用の列を追加する必要がある。既存ジョブに曲名がない場合は、従来どおり下書き名を使って完了させる。
