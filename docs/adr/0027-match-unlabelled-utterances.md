# ADR 0027: 話者ラベルのない発話を登録音声と個別照合する

Date: 2026-10-13

## Status

Proposed

## Context

内部テスト録音では、Googleの単語情報に本文と時刻がありながら話者ラベルがない場合があった。[ADR 0025](0025-unlabelled-transcript-review.md)に沿って発話を `unknown` として保持し、[ADR 0026](0026-manual-transcript-speaker-review.md)に沿って確認画面で手動割当てできるが、選択プロフィールが複数あると声紋照合は実行されず、発話が多い場合は確認の手間が大きい。

既存の登録音声との照合は[ADR 0012](0012-named-speaker-enrollment.md)の提案にあり、cosine similarity 0.65以上かつ次点との差0.10以上という保守的な基準を使う。日本語の個別発話に対する識別精度は未確認である。

## Decision

各 `unknown` 発話を別々の短い音声区間として切り出し、録音で選んだプロフィールと個別に比較する。ほかの重なる発話区間は照合音声から除く。最低3秒の音声と1.5秒の有声音を含み、既存の一致基準を満たすときだけプロフィール名を仮割当てし、それ以外は `unknown` のまま確認画面へ渡す。1チャンクの推論は最大60発話に制限する。

話者ラベルのない単語を長い一つの音声として照合する案は、別人の発話を混ぜてしまうため採用しない。未特定発話をすべて手動割当てにする案は、画面の確認負荷を増やすため採用しない。自動照合後も文字起こしの確認を要求し、未特定の行は原音再生と手動割当てを可能にする。歌詞作成は利用者が確認を進めた後に行う。

## Consequences

- 利点: Googleの話者ラベルが欠けても、複数の登録参加者から一致候補を付けられる。短い未特定発話を別々に扱うため、会話の異なる話者を一つの声紋に混ぜない。
- 受け入れる欠点: 短い・重なる・60件を超える発話は自動照合できないことがあり、未特定のまま確認に残る。閾値を満たしても誤った候補になる可能性はあり、日本語音声での品質受け入れを示すものではない。Cloud Runの推論時間と実機の割当て品質を測る必要がある。

## 確認

ローカルでは、話者ラベルのない発話の分割、重なり区間の除外、複数プロフィールを用いるWorkflowへの発話ID伝達、確認待ち後の歌詞作成をテストする。実機受け入れでは、登録音声と実際の会話を比較し、声の誤割当て、文字起こしの欠落、歌詞が作成されて確認できることを試聴・画面操作で確認する。
