# ADR 0032: Androidの完成曲を利用者が選んだ保存先へ書き出す

Date: 2026-10-13

## Status

Proposed

## Context

完成曲をアプリ外のファイルとして受け取れる必要がある。既存の再生用APIは認証後に期限付き音源URLを発行する。曲はMP3で保存し、端末内の再生専用キャッシュや別形式の変換は追加しない。

保存先で作られたMP3は、アプリの思い出レコードとは別に利用者が選んだファイルとなる。思い出またはアカウントを削除した後の扱いを、画面とプライバシーポリシーで一貫させる必要がある。

## Decision

Android標準の `ACTION_CREATE_DOCUMENT` で保存先と初期ファイル名を選び、アプリの非公開キャッシュに取得したMP3をネイティブ側でストリームコピーする。追加のストレージ権限を要求せず、MP3の内容をBase64でJavaScriptへ展開しない。取得済み音源と失敗した保存の途中ファイルは可能な範囲で消去し、保存完了後の外部ファイルは思い出・アカウントの削除対象に含めない。

OSの保存画面へファイルを作る方式と、保存先選択を伴わずアプリ領域に置く方式の差は、利用者がファイルを通常のMP3として管理できるかどうかである。本機能では利用者が保存場所を選ぶ必要があるため、標準のファイル作成画面を使う。

## Consequences

- 利点: Androidの標準保存先・名前選択を使い、生成済みMP3を変換せず利用者が管理できる。
- 受け入れる欠点: 保存先プロバイダーの停止や容量不足によりコピーが失敗しうる。取り消し時の途中ファイル消去は保存先プロバイダーに依存する。
- 確認: Androidネイティブビルド、保存画面、同名保存、キャンセル、途中失敗時の消去、取得元と保存後のサイズ・ハッシュ、外部プレイヤー再生を確認する。
