# ADR 0016: 思い出ごとに参加する話者を選ぶ

Date: 2026-10-06

## Status

Accepted

採用確認: 2026-10-06 のチャットで、ユーザーが新しい記録ごとに登録済み話者を選び、思い出ごとに異なる人の組み合わせで作れるよう求めた。

## Context

ライブラリのプラスボタンは下書きを新規作成するが、話者を選ぶ段階はない。準備ジョブはアカウントに登録された話者をすべて照合対象として固定するため、同じアカウントに登録した人たちを思い出ごとに分けられない。

## Decision

プラスボタンから新しい記録を始める前に、登録済み話者を1人以上選ぶ。選択したプロフィールIDを端末の下書きとサーバーの下書きに保存し、準備ジョブでは選択されたプロフィールだけを識別対象として固定する。完成曲にも選択されたプロフィールIDを引き継ぐ。

選択のない既存下書きは、更新前の動作との互換性のため、従来どおりアカウントの登録話者を照合対象とする。

## Consequences

- 利点: ひとつのアカウント内で思い出ごとの参加者を分けられ、選択内容が録音後の話者識別にも反映される。
- 受け入れる欠点: 選択した話者が準備前に削除されると、その話者を含む下書きは準備を開始できない。端末とサーバーの下書きに参加者IDを保持する必要がある。

[ADR 0009](0009-local-durable-drafts.md) の端末内下書き保存と、[ADR 0012](0012-named-speaker-enrollment.md) の準備開始時の話者情報固定に沿う追加仕様である。ADR 0012 の声紋モデル・閾値・推論基盤に関する Proposed 判断は採用しない。
