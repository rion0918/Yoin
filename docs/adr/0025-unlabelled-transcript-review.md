# ADR 0025: 話者ラベルのない文字起こしを未特定のまま確認する

Date: 2026-10-13

## Status

Proposed

## Context

内部テストで、Googleの文字起こし応答に単語・時刻はある一方、話者ラベルがない録音が発生した。保存済み応答を復旧するときも同じ解析器を通るため、ラベルの欠落だけで応答全体が拒否され、音声と応答が保存済みでも発話・歌詞が作成されなかった。話者ラベルを推測で補うと、誤った人物に発話を結び付ける。

音声品質と有料API結果を保存して再利用する制約は[ADR 0010](0010-google-audio-quality-trial.md)、不確かな認識を人が確認してから進める制約は[ADR 0023](0023-transcript-timing-review.md)に従う。

## Decision

単語時刻と本文が有効なら、話者ラベルがない発話を `unknown` として保持し、直前の話者を引き継がない。話者識別器は未特定の区間を除外し、録音で選ばれた話者が1人だけの場合に限り、その登録音声との照合を試す。照合結果の有無にかかわらず、未ラベル発話または保存済み応答から復旧した文字起こしは `needs_audio_review` で待機し、利用者が原音と全文を確認してから歌詞を作る。

文字起こしAPIを再送する案は、保存済み応答を利用できる場合に重複課金の可能性を増やすため採用しない。欠けた話者を直前のラベルで補う案は、話者の誤帰属を隠すため採用しない。

## Consequences

- 利点: 本文・時刻を捨てずに復旧でき、話者の不確かさを表示して確認を挟める。複数人が選ばれた録音では未特定の発話を自動で割り当てない。
- 受け入れる欠点: 話者ラベルがない録音は利用者の確認が必要になる。1人の登録音声との照合も、本人確認の確証にはならないため、確認待ちを省略しない。

## 確認

保存済み応答からの復旧でGoogleへの再送がないこと、本文と時刻が保持されること、未特定話者を複数プロフィールへ自動割当しないこと、確認前に歌詞を作成しないことをテストと内部テスト実機で確認する。
