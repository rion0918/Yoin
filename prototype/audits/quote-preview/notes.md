# 引用プレビューの確認

対象: 旅行の曲の詳細画面にある、歌詞・引用文・会話ボタンの情報構成。現在のブラウザ画面を使った限定レビュー。

1. 歌詞画面（01-lyrics.jpg）: 日時・場所は場面を識別でき、歌詞が主役になっている。一方で「閉店まであと5分」とアオイ「あと5分らしいぞ！」は意味が重なり、毎場面の表示量を増やしている。会話を開くボタンがあるため、引用文の役割は弱い。

推奨: 一覧は日時・場所 → 歌詞 → 会話ボタンの3段にする。発言者名と発言は詳細に置く。引用プレビューが独自の場面情報を加える場合には別途評価する。

アクセシビリティの観察: 引用文は歌詞より小さく淡い表示。引用文だけに必須情報を持たせない構成が望ましい。画面の見た目だけではコントラスト適合や支援技術での読み上げは判定できない。

2. 会話を開く（02-conversation.jpg）: 正しい日時・場所のシートが開き、アオイの発言に加えてレオンとユウの会話、その会話から生まれた歌詞を確認できる。元の発言と発言者をここに残せば、歌詞画面から引用プレビューを外しても情報は失われない。

結論: 現在のコピーでは引用プレビューを外す案を推奨。発言者や会話の温度感は詳細で伝え、一覧では歌詞への注意を保つ。現在の2画面の構造とコピーに基づく判断であり、引用の有無による開封率や満足度はユーザーテストしていない。アプリの実装は変更していない。
