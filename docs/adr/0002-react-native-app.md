# ADR 0002: 本実装にReact Nativeを使用する

Date: 2026-10-04

## Status

Accepted

採用確認: 2026-10-04 のチャットで、ユーザーが「実装するならreactnative」と指定した。

## Context

Yoin では、会話を記録し、その会話から作った曲と思い出を聴き返すモバイルアプリを検討している。現在の `prototype/` は React/Vite で画面構成と操作を検証する Web プロトタイプであり、録音・位置取得・楽曲生成はモックである。

本実装へ進む前にアプリのフレームワークを記録する必要がある。ユーザーは本実装に React Native を使用する方針を指定しており、この判断はすでに[プロトタイプのエージェントガイド](../../prototype/AGENTS.md)にも記載されている。

## Decision

Yoin のモバイルアプリの本実装には React Native を使用する。採用根拠はユーザーの指定であり、今回ほかのフレームワークとの比較検討は行っていない。

現在の `prototype/` は UI 検証用として維持し、画面構成・操作・デザイン・モックデータを本実装の参照に使う。Web プロトタイプが存在することを、ネイティブ機能の実装完了とは扱わない。

Expo の使用、録音ライブラリ、端末内保存、バックエンド、音声処理・楽曲生成 API はこの ADR では決定しない。選定が必要になった段階で、[ADR 運用ガイド](README.md)に従って別の判断として記録する。

## Consequences

- 利点: 本実装のフレームワークが明確になり、React Native を前提に実装を進められる。既存プロトタイプを画面と操作の参照に使える。
- 受け入れる欠点: Web の DOM・CSS・端末シミュレーターはそのまま本実装の UI として使えず、React Native 向けに実装する必要がある。実際の録音や保存、楽曲生成の実装と検証は今後の作業として残る。
