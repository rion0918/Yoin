# ADR 0023: 不正な認識時刻は全文と元音声を保持して確認を待つ

Date: 2026-10-12

## Status

Accepted

採用確認: 2026-10-12のチャットで、Googleの完了済み応答に開始3.9秒・終了1.1秒の単語時刻がある事例を提示した。ユーザーは「元音声・全文を保持し、時刻不整合を表示して確認後に続行する」を選択した。

## Context

実APIの文字起こし303語のうち1語に、終了が開始より前の時刻が含まれた。全文と利用量を含む完了応答は非公開R2に保存済みだが、従来の解析は応答全体を拒否し、費用の照合待ちになった。時刻を推測で入れ替えたり、その語を削ったりすると、会話や出典の正確さを失う。

## Decision

完了応答の本文・元音声・不正な時刻を保持する。単語時刻が不正な区間では、検査済み音声区間の全体を出典範囲として全文を残し、個々の発話時刻と話者名は確定したものとして扱わない。音声確認画面に時刻不整合を表示し、利用者が原音と全文を確認して続行するまで歌詞を生成しない。通常の有効な認識時刻の処理は維持する。

保存済みGoogle応答がある文字起こしは、認証・所有者・元の試行・検査済み音声区間を照合して解析を回復する。GoogleへのPOSTを再送せず、保存した利用量から既存の試行と費用を照合する。応答のない試行の予約は保持し、台帳を初期化しない。配置はmainのCIを使用する。

関連する採用済み判断はADR 0009・0010・0011・0013。音声範囲の確認案はADR 0018にProposedとして残っており、この記録でそのStatusは変更しない。

## Consequences

- 利点: 会話を欠落させず、追加課金や推測した単語時刻を使わずに確認後の生成へ進める。
- 受け入れる欠点: 該当区間の出典は音声区間全体となり、細かな発話時刻と話者名は未確認になる。原音の試聴と内容確認が必要である。
- 確認: 回復時のGoogle送信0回、全文・原音・不正時刻の保持、承認前の歌詞生成0回、所有者境界、予算保持、確認後の生成と再生を検証する。
